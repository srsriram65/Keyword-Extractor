---

## 📌 About the Project

This repository contains 10 practical applications developed as part of the
**Text and Speech Analysis** course.

The applications demonstrate fundamental concepts in:

- 📝 Text Processing
- 🔤 Natural Language Processing
- 📊 Text Analysis
- 🤖 Machine Learning Concepts
- 🔊 Speech Processing
- 🌐 Web-Based Applications

All applications are designed with simple and user-friendly interfaces.

---

## 🎯 Objectives

The main objectives of this project are:

- Understand basic Text and Speech Analysis concepts.
- Implement NLP techniques using programming.
- Analyze and process textual data.
- Develop simple interactive applications.
- Understand how speech and text can be processed computationally.
- Gain practical experience with HTML, CSS and JavaScript.
- Organize and manage projects using GitHub.
